# Code review: readability (Hermione) - knitting-increase-calculator

Verdict: readable and well commented overall, but one page claim contradicts the tool's real output (1 must-fix), plus a stale JSDoc, a few mixed terms and some small leftovers. Must-fix count: 1.

Checked by hand: article and table examples (50/+7 flat, 100/-10 flat, 60/+12 round, 40/+8, 72/+12, 80/+10, 96/-8 round) all match `plan()` output. Edge runs (1 stitch, k>n, 2 stitches decrease, 20/60 round) give sensible text.

Known template leftovers (README, new-tool.sh, tracked screenshots, duplicate legal links on home, build-date "Last updated", British spelling) are on the fixer's list and not repeated here.
